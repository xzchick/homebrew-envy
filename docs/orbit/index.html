ENVY Orbit: Recurring cadence tracker for key rotations, reviews and routines

ENVY Orbit tracks things that have to happen on a cadence, like rotating keys, reviewing access or backing up, and shows what's due, what's overdue and how consistent you've been.

Free & open source (MIT)Works offlinemacOS · Windows · Linuxv0.2.2

Download v0.2.2Source on GitHub

What it does

  • Tracks with a cadence: see what's due and what's overdue
  • Snooze a track without breaking its schedule
  • Streaks to show consistency over time
  • Export to iCal for your calendar
  • AES-256-GCM encryption with a hash-chained journal

Install

macOS (Homebrew)

brew tap xzchick/envy https://github.com/xzchick/homebrew-envy
brew install --cask envy-orbit

Linux (one line; verifies the signed checksums)

curl -fsSL https://raw.githubusercontent.com/xzchick/envy-orbit/main/install.sh | sh

Windows: download the zip from the latest release.

Questions

Is ENVY Orbit free?

Yes. It is free and open source under the MIT licence; the source is on GitHub.

Does it need an internet connection?

No. It runs entirely on your own machine: no network access, no accounts and no telemetry.

What happens if I forget my passphrase?

The data can't be recovered. There is no back door or recovery by design, so keep your passphrase somewhere safe.

Which platforms does it run on?

macOS, Windows and Linux. It's a native desktop app (PyQt6), not a web page or Electron wrapper.

How do I know the download is genuine?

Every release is signed with Sigstore and ships a CycloneDX SBOM. Verify the checksums with cosign verify-blob; the steps are in the repository README.

Honest limits

Young, solo-built project with no third-party security audit yet. It structures and protects your own work; it supplies no facts and makes no verdicts.
