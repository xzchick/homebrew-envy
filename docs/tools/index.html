ENVY Tools: Install and update every ENVY app on any OS

ENVY Tools is the one app you need to get the rest of the suite. It lists every ENVY app, installs the standalone build made for your computer after checking it against the release's checksums, adds it to your Start Menu, Applications folder or app menu, and tells you when updates are out.

What it does

  • Every ENVY app in one searchable list, kept current from GitHub (with a built-in copy for offline use)
  • Installs the right standalone build for your OS and CPU, so no Python is needed
  • SHA-256 verified before unpacking; Sigstore signature verified when cosign is installed
  • Safe unpacking that refuses paths or links escaping the app folder
  • Start Menu shortcuts on Windows, Applications entries on macOS, app-menu entries on Linux
  • One-click updates per app, or update everything at once
  • Removes exactly what it installed, never your own files
  • No administrator rights; every network request shown

Install

macOS (Homebrew)

brew tap xzchick/envy https://github.com/xzchick/homebrew-envy
brew install --cask envy-tools

Linux (one line; verifies the signed checksums)

curl -fsSL https://raw.githubusercontent.com/xzchick/envy-tools/main/install.sh | sh

Windows: download the zip from the latest release.

Questions

Is ENVY Tools free?

Yes. It is free and open source under the MIT licence; the source is on GitHub.

What does it connect to?

Only GitHub, over HTTPS: to read the app list and download the apps you choose. Every request is shown in its log, there's no telemetry or account, and --offline uses the built-in list.

Which platforms does it run on?

macOS, Windows and Linux. It's a native desktop app (PyQt6), not a web page or Electron wrapper.

How do I know a download wasn't tampered with?

Every bundle's SHA-256 must match the release's checksum file before anything is unpacked. If cosign is installed, ENVY Tools also verifies the Sigstore signature on that file, proving the app's own release workflow built it.

Does it need administrator rights?

No. Apps are installed into your own user folders, with a Start Menu shortcut, an app in ~/Applications, or an app-menu entry.

Do I need Python?

No. It installs each app's standalone build, which carries its own runtime.

How do I know the download is genuine?

Every release is signed with Sigstore and ships a CycloneDX SBOM. Verify the checksums with cosign verify-blob; the steps are in the repository README.

Honest limits

Young, solo-built project with no third-party security audit yet. It structures and protects your own work; it supplies no facts and makes no verdicts.
