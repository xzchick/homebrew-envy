ENVY BLACK VEIL

Eleven small, offline desktop tools for privacy, security and analysis. Nothing leaves your machine — no network, no accounts, no telemetry.

AES-256-GCM at rest SHA-256 hash-chained journal Sigstore-signed releases + SBOM PyQt6 native · not Electron macOS · Windows · Linux MIT

The apps

ENVY Vault

Authenticated local AES-256 file encryption in a native window.

brew install --cask envy-vault

ENVY Veil

Offline LSB image steganography with an AES-256 payload.

brew install --cask envy-veil

ENVY Hypothesis

Analysis of Competing Hypotheses as an offline native app.

brew install --cask envy-hypothesis

ENVY Oracle

Offline prediction & calibration tracker with Brier scoring.

brew install --cask envy-oracle

Install

macOS — Homebrew

brew tap xzchick/envy https://github.com/xzchick/homebrew-envy
brew install --cask envy-vault

Linux — one line (verifies against the signed checksums)

curl -fsSL https://raw.githubusercontent.com/xzchick/envy-vault/main/install.sh | sh

Windows / any platform

Download the standalone bundle from each repo's Releases page. Every release ships a Sigstore signature and a CycloneDX SBOM; verify a download with cosign verify-blob (see each repo's “Verifying a release”).

Honest caveats

Young project, solo-built, and no third-party security audit yet. There is no passphrase recovery by design — lose the passphrase and the data is gone. The apps supply no facts and make no verdicts; they structure and protect your work.
