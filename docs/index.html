ENVY BLACK VEIL

Free, offline desktop tools for privacy, security and analysis

Eleven small, open-source apps that never go online: no network, no accounts, no telemetry. AES-256-GCM at rest, SHA-256 hash-chained journals, and Sigstore-signed releases with an SBOM. Native windows for macOS, Windows and Linux.

The apps

ENVY Vault

Offline file encryption app for macOS, Windows and Linux

ENVY Veil

Steganography app: hide encrypted files inside images and audio

ENVY Hypothesis

Analysis of Competing Hypotheses (ACH) software, offline and encrypted

ENVY Oracle

Forecast tracker with Brier scores and calibration charts

ENVY SkyWatch

Offline keyword, regex and hash watchlist scanner for files and logs

ENVY Casebook

Encrypted case notes app for investigations

ENVY Crypto Workbench

Offline encoding and classical cipher workbench

ENVY Orbit

Recurring cadence tracker for key rotations, reviews and routines

ENVY Ops Desk

Offline operations planner with authenticated handoffs

ENVY Evidence Vault

Chain of custody evidence log software, offline and hash-verified

ENVY Integrity Monitor

File integrity monitoring (FIM) desktop app

Install

macOS

brew tap xzchick/envy https://github.com/xzchick/homebrew-envy
brew install --cask envy-vault

Linux: each app's page has a one-line installer that verifies the signed checksums. Windows: download from each app's Releases page.

Honest caveats

Young, solo-built project with no third-party audit yet. Encrypted apps have no passphrase recovery by design.
