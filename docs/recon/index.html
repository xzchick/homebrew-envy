ENVY Recon: OSINT terminal for domains, IPs, certificates and file metadata

ENVY Recon is a standalone terminal for open-source intelligence on infrastructure and files. Point it at a domain, IP address, URL or file and it gathers what public sources say, showing every network request as it happens. No API keys and no account.

What it does

  • Domain reports in one command: DNS, RDAP/WHOIS, TLS, HTTP, certificates and archive history
  • DNS records (A, AAAA, MX, NS, TXT, SOA, CAA) and SPF
  • IP addresses: reverse DNS, ASN and owner, prefix, country and RDAP network
  • Hostnames from certificate-transparency logs (crt.sh) and Wayback Machine snapshot history
  • HTTP redirect chain, security headers and cookie flags; TLS certificate details
  • Offline file metadata: hashes, EXIF with GPS map links, PDF info, Office document authors
  • Every network request is printed; offline mode blocks them all
  • Export a session to Markdown or JSON with its SHA-256

Questions

Is ENVY Recon free?

Yes. It is free and open source under the MIT licence; the source is on GitHub.

What does it connect to?

Only public sources (DNS, RDAP, Team Cymru, crt.sh, the Wayback Machine) and the target you name. Every request is shown as it happens, there's no telemetry or account, and offline mode blocks all network access.

Which platforms does it run on?

macOS, Windows and Linux, as a standalone terminal app with no Python install needed.

Can the target see my lookups?

Header and TLS checks connect to the target directly, and lookups come from your own IP address. Use a network you control if that matters.

How do I know the download is genuine?

Every release is signed with Sigstore and ships a CycloneDX SBOM. Verify the checksums with cosign verify-blob; the steps are in the repository README.

Honest limits

Young, solo-built project with no third-party security audit yet. It structures and protects your own work; it supplies no facts and makes no verdicts.
